# Archive

This directory contains deprecated scripts and modules that have been removed from the main project structure.

These files are kept for historical purposes and reference only. They may not be maintained or compatible with the current codebase.

## Contents

- **tools/atomicblastplus.py**: Deprecated tool for submitting parallel BLAST+ jobs to a SGE cluster. Last updated in 2016.

## Note

Please do not use these archived scripts in production environments. They are no longer supported or maintained and may contain bugs or security issues.

If you need functionality similar to what's provided by these archived scripts, please check the current project documentation for modern alternatives or contact the project maintainers.
