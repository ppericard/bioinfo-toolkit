# Deprecated Tools

This directory contains tools that have been deprecated and are no longer maintained. They are kept here for historical reference only.

## atomicblastplus.py

A deprecated tool for submitting parallel BLAST+ jobs to a SGE cluster. Last updated in 2016.

This script has been removed from the main codebase as it:
- Relies on outdated technology (Oracle Grid Engine/Sun Grid Engine)
- Is no longer maintained
- Has been superseded by more modern alternatives

**Warning**: This script is provided for historical reference only and should not be used in production environments.
